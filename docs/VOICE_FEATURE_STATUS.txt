================================================================================
                             HOW TO USE NOW
================================================================================

ACCESS THE APP:
  URL: http://localhost:5173
  Backend API: http://localhost:5000/api

RECORD A VOICE RESPONSE:
  1. Click on a candidate name
  2. Click "Start Interview"
  3. You'll see two tabs:
     - Interview (traditional)
     - 🎤 Voice Interview (glowing button - click this!)
  4. Click "Start Recording"
  5. Speak clearly for 10-30 seconds
  6. Click "Stop Recording"
  7. Wait ~1 second for processing
  8. See transcript and scores appear

VIEW COMMUNICATION SCORES:
  1. Transcript displays automatically
  2. Communication Score (0-100) shown prominently
  3. Four metrics displayed:
     - Clarity: 0-100
     - Confidence: 0-100
     - Relevance: 0-100
     - Speaking Pace: 0-100
  4. Visual progress bars for each metric
  5. Analysis note explaining results

RECORD MULTIPLE RESPONSES:
  1. Click "Record Again" to re-record same question
  2. Or switch to next question
  3. Each recording is stored separately
  4. Profile automatically averages all recordings

CHECK CANDIDATE PROFILE:
  1. Navigate to candidate detail page
  2. Look for "Communication" score ring (amber color)
  3. See voice profile metrics breakdown
  4. Communication score updates based on recordings
